# 평소 매출 baseline (V4)

폭염·호우가 매출에 준 영향을 재려면 먼저 **"그날 날씨가 평소 같았다면 얼마 팔렸을까"** 를 알아야 합니다. 이 폴더는 그 평소 매출(baseline, $B$)을 지역 × 업종 × 시간대 × 날짜 단위로 예측하는 코드입니다.

다음 단계(기상 모델)에서는 이 $B$로 아래 값을 만들어 씁니다.

$$y_{slot}=\frac{S_{slot}-B_{slot}}{\sum_{slot} B_{slot}}\qquad(\text{분모} = \text{그날 그 업종 4개 시간대 } B\text{ 합})$$

## 최종 모델 (V4)

| 항목 | 설정 |
|---|---|
| 모델 | XGBoost `reg:tweedie`(variance power 1.5). 목표값 = 매출 / 1만 원. **평균**을 예측함 (기간 합계·피해 금액이 맞도록) |
| 하이퍼파라미터 | n_estimators 1000, learning_rate 0.05, max_depth 8, min_child_weight 5, subsample 0.8, colsample_bytree 1.0, tree_method hist, random_state 42 |
| 학습 데이터 | **평시 날만**: 폭염·호우 특보 없음 & 일강수 10mm 미만. 한파·대설 날은 데이터에서 제외. 휴무 칸도 학습에 포함 |
| 교차 적합 | ISO 주차 % 5 → 5묶음. 예측하는 주 ±3일은 학습에서 뺌. 모든 날짜를 그 날을 보지 않은 모델로 예측 |
| 공휴일 처리 | 공휴일에 `요일`=6(일), `주말`=1로 바꿔 넣음(`공휴일`=1은 유지). **강남 전 업종 + 춘천 11개 업종**에만 적용 |
| 사후보정 | 없음 |

**전처리**: 법인·세금공과금·ZZ_나머지 제외 → 날짜×지역×업종×시간대 격자(결제 없으면 0) → 매출 > 0인 날이 80% 미만인 칸 제외. 특보 등급 = 경보 2 / 주의보 1 / 없음 0. 휴무 칸 = 그 칸·그 요일(공휴일은 따로)의 평시 날 중 절반 이상이 매출 0.

## 검증 방법

평시 날(날씨 충격이 없는 날)에는 $y$가 0 근처여야 합니다. 휴무 칸은 빼고, 아래 순서로 봅니다.

| 순위 | 지표 | 보는 이유 |
|---|---|---|
| 1 | 평시 y 편향: 금액가중 $y=\sum(S-B)/\sum B_{하루합}$, y 중앙값, \|t\|>2 칸 비율(약 5%면 정상), 월별 편향 | baseline이 한쪽으로 치우치면 날씨 효과로 잘못 잡힘 |
| 2 | y 잡음: 칸별 y IQR, 업종 하루 y IQR | 잡음이 크면 날씨 효과가 묻힘 |
| 3 | 실제 사건 규모 합계: 요일을 맞춘 평시 날을 무작위로 뽑아(폭염 46일, 호우 8~9일, 300번) 합계 오차 | 피해 금액은 기간 합계로 계산 |
| 4 | 시간대 비중 오차 | 시간대 단위로 예측하므로 |
| 5 | MdAPE / WAPE | 참고 |

단순 평균 y는 분모가 작은 칸에 끌려가서 금액가중 y를 씁니다. MAE·WAPE는 중앙값 모델에, RMSE·합계는 평균 모델에 유리하다는 점도 감안해서 읽습니다.

## 주요 결과 (실제 데이터)

**V4 vs 공휴일 처리 전(V0)** — 36번
- 강남 공휴일 하루 편향 |평균| 30.5% → 15.2%, 10/8 −42% → −4%
- 8/15: 강남 −21% → +4%, 춘천 −5% → −1%
- 공휴일이 아닌 날의 지표는 거의 그대로입니다. 다만 \|t\|>2 칸 비율(3.8 → 5.7%)과 폭염 시즌 합계 편향(+0.2~0.6%p)은 조금 올랐고, 추석 연휴 날 때문인 것으로 보입니다.

**V4 vs 팀원 B2-strict** — 37번, 두 모델 모두 있는 344칸
- V4가 나은 것: \|t\|>2 칸 비율 2.3% vs 8.4%, y IQR 9.1 vs 10.1, WAPE 17.5% vs 18.6%, 시즌 합계 오차·90% 범위, 시간대 단위 오차, 추석·8/15, 8월 편향(−1.0% vs −2.3%)
- B2가 나은 것: 전체 금액 편향 0.03% vs 0.39%, 시즌 합계 편향 −0.2/−0.3% vs +1.0/+1.6%
- → V4를 유지합니다. 남는 평시 편향은 기상 모델 단계에서 지역별 평시 평균 $\bar y_{평시}$를 빼서 보정하는 방안을 검토 중입니다.

## 한계

- 긴 연휴는 데이터에 추석 한 번뿐이라 추석 연휴(10/2~10/9)와 12/24~25는 오차가 큽니다. 검증·기상 모델에서는 `특수일` 열로 따로 보거나 뺍니다.
- 7~8월은 폭염 특보가 많아 평시 날이 적고, 그래서 여름 계절 효과가 baseline에 충분히 반영되지 않았을 수 있습니다.
- 강남 보험처럼 결제일에 목돈이 몰리는 업종은 금액 오차의 상당 부분을 차지합니다(34번: 강남 보험이 절대 금액 오차의 23%). 업종 제외는 이유를 정리한 뒤 결정하기로 하고 보류 중입니다.
